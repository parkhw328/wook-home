다음 공간에서도 이어갈 수 있도록.

먼저 사무실을 중지해 진행 중인 업무를 저장하세요. 직원과 업무 기록을 파일로 내려받아 다음 작업을 준비할 수 있습니다.

  1. 01
    업무를 잠시 멈추기

    새 업무 접수와 진행을 중지하고 현재 상태를 보존합니다.

  2. 02
    인계 기록 내려받기

    직원, 업무, 대화, 결과를 포함한 JSON 파일을 저장합니다.

  3. 03
    내용을 검토한 뒤 공유하기

    입력한 내용이 포함됩니다. 공유할 정보인지 먼저 확인하세요.

사무실 중지는 내부 업무에만 적용되며 외부 CLI를 중지하지 않습니다. 파일 가져오기, 다른 PC의 세션 복원, GitHub 자동 전송은 준비 중입니다.

현재 작업 상태

중단된 업무는 완료 처리되지 않습니다. 같은 저장소로 서버를 다시 실행하면 저장된 상태를 확인할 수 있습니다.
