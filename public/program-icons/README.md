# 프로그램 아이콘

wShell·wPost·wText 카드에서 각 프로젝트의 실제 앱 아이콘을 자체 제공한다. 아래 원본 PNG를 변경 없이 복사했으며, 색·비율·투명 여백을 유지한다. 아이콘은 카드에서 56px(3.5rem) 정사각 영역 안에 `object-fit: contain`으로 표시한다. 이름은 별도 텍스트로 제공하므로 이미지의 대체 텍스트는 비워 중복 낭독을 피한다.
