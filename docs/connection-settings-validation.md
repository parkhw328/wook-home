## Docker

Node.js 24.14.0 이미지의 비루트 UID 1000 서버와 같은 UID의 호스트 연결기를 별도 환경에서 실행했다. 상태 폴더는 읽기 전용, 설정·지시 폴더는 읽기·쓰기 마운트다. HTTP 설정 저장→호스트 응답→공개 대화 열람, 서버 컨테이너 재시작 뒤 설정 복원과 끄기를 확인했다. 코드·정적 자산 외의 로컬 대화·설정·검증 자료는 이미지에 넣지 않는다.

Linux의 서로 다른 UID를 자동 변경하거나 세계 공개 권한으로 넓히는 기능은 추가하지 않았다. 저장할 수 없는 폴더와 호스트의 읽기 실패는 화면에서 다음 조치를 안내한다. Windows 실제 실행, 실제 계정 지시 전송과 SELinux enforcing 환경은 이번 추가 검증 범위에 포함하지 않았다.
