## 실제 브라우저

분리 사본의 Node 서버와 검증용 데이터를 사용해 Chromium에서 **화면 검사 92개와 상호작용 상태 검사 118개, 총 210개**를 통과했다. 화면 캡처를 함께 확인했다.

- 라이트·다크 각각 320·390·768·1366·1920px에서 사무실·업무 보드·자료 검색·작업 인계와 채용·직원 상세·CLI 대화·보관 대화창을 확인했다. 최종 계산 글꼴은 보조 정보 14px 이상, 버튼·입력 16px 이상이며 글자 대비와 가로 넘침을 검사했다.
- 업무보고·답변 초안·대화 검색·필터·스크롤 위치가 테마 전환 후 유지됐다. 실제 전체화면 전환, 기기 설정 추종, 새로고침 복원, 탭 간 동기화와 저장소 접근 차단 상황을 확인했다.
- 200% 글꼴 확대와 683px 너비에서 네 주요 화면의 재배치·대비·가로 넘침을 확인했다. 브라우저 자체 확대율을 바꾼 검사는 아니다.
- 1366px의 두 테마에서 주요 화면, 감지·점검·설정 탭, 선택한 설정, 채용·직원 연결·직원 상세·CLI·보관 대화창과 전체화면의 기본·포인터 올림·누름·초점 상태를 검사했다. 브라우저 개발자 프로토콜로 의사 클래스를 적용했으며 이 검사에서만 주기적 갱신을 멈춰 검사 중 요소 교체를 방지했다. 별도의 화면 검사에서는 실제 갱신을 유지했다.
- 표시 중인 요소와 가상 요소의 계산된 `box-shadow`, `text-shadow`, `drop-shadow`를 검사해 UI 그림자가 없음을 확인했다. 캐릭터의 머리·눈·옷을 그리는 CSS 표현은 UI 그림자 검사에서 제외했다.
- 키보드로 선택한 층 버튼에 3px 파란 초점선, 700 굵기와 선택 테두리가 함께 보이고 그림자는 없음을 확인했다. 강제 색상 모드에서도 초점선을 유지했다. 일반·오류 알림에도 그림자 없이 테두리를 적용했다.

글자 대비 부족, 가로 넘침, UI 그림자와 자바스크립트 실행 오류는 발견되지 않았다. 정상·주의·오류·종료 상태 색상과 아이콘은 기존 의미를 유지한다.
