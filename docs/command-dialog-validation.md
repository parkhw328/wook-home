# 지시 모달 확대 검증 — 2026-10-30

## 변경

0.2.5는 일반 상세창과 같은 620px 폭을 사용하던 지시 화면을 최대 1,200×900px로 넓힌다. 실제 크기는 화면의 가로·세로 여백 안으로 제한한다. 실제 CLI·연결된 직원·체험 업무 작성 화면에 적용한다.

넓은 화면의 CLI 지시는 왼쪽 입력과 오른쪽 직원·연결 정보로 나눈다. 작은 화면은 입력부터 표시하고 본문 한 곳을 스크롤해 관리 정보에 접근한다. 체험 업무의 짧은 필드는 나란히 배치하고 설명 입력에 남은 높이를 사용한다. 입력창은 기존 4~5줄에서 12줄로 넓히며 최소 높이는 16rem이다. 글자 크기, 기존 4,000자 제한과 지시 전송 API는 유지한다.

공통 모달의 닫기·초점·요청 처리는 그대로 사용한다. 일반 직원 설정 등 다른 상세창으로 전환하면 기존 폭으로 돌아간다.

## 검증 결과

- Node.js 26.8.1의 `npm test`: 249개 통과.
- 배포 이미지의 Node.js 24.14.0: 248개 통과·1개 조건부 제외. 다른 비루트 UID를 구성하는 권한 검사는 비루트 컨테이너의 실행 조건에 해당하지 않으며 호스트에서는 통과했다.
- 기존 `tests/browser/density.py`: 290개 화면·상호작용 점검 통과. 두 테마, 320·390·768·1366·1920px와 실제 Chromium 200% 확대에서 가독성·44px 조작·가로 넘침·단일 모달·입력과 닫기 흐름을 확인했다.
- 지시 화면 집중 점검 42개: 위 화면 조합에 844×390px 가로 화면을 더해 실제 직원·독립 CLI·체험 업무 세 경로를 확인했다. 4,000자 초안, 닫기·재열기·Escape·바깥 클릭, 모델·강도 선택, 갱신 중 커서·입력 스크롤, 일반 설정창으로의 전환을 확인했다.
- 1366×900px에서 지시 모달은 1,200×868px, 실제 CLI 입력창은 약 761×329px로 표시된다. 지시 전송 버튼을 가리지 않으며 긴 연결 정보는 본문 스크롤로 확인한다.
- 라이트 데스크톱과 다크 모바일 캡처를 직접 확인했다. 브라우저 오류와 페이지·모달 본문의 가로 넘침은 없었다.
- 사무실 전체화면의 1366px 라이트·390px 다크에서도 지시 작성·전송 버튼 접근·Escape 닫기를 확인했다. 모달만 닫고 전체화면을 유지한 뒤 정상적으로 일반 화면에 복귀했다.

브라우저 검증은 합성 계정·직원·CLI 기록을 사용하는 `tests/browser/density-preview.mjs`에서 수행했다. 실제 계정·업무 DB·호스트 CLI 지시 전송은 사용하지 않았다. 결과와 캡처는 Git 제외 `artifacts/density/`와 `artifacts/command-dialog/`에 보관한다.

## 재현

[개발 안내](development.md#화면-밀도계정-변경-검증)의 합성 서버와 `density.py`를 실행한다. 지시 화면은 직원 관리의 연결된 직원 → 대화창의 **직원 정보**, 대화창의 **이 세션에 지시**, 업무 보드의 **업무 지시**에서 각각 연다. 긴 내용을 입력하고 닫기·재열기, 모델 선택 후 자동 갱신, 스크롤 뒤 전송·닫기 접근과 일반 직원 설정창 전환을 확인한다.
