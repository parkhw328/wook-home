# 관리자 로그인

0.2.0부터 사무실 화면과 업무·대화·검색·인계 API는 로그인이 필요합니다. 계정은 `admin`이며 최초 실행 때 무작위 초기 비밀번호를 발급합니다. 공용 기본 비밀번호는 없습니다.

## 최초 입장

1. 서버를 실행하고 사무실 주소를 엽니다.
2. 서버 PC의 로컬 데이터 디렉터리에서 `admin-initial-password.txt`를 확인합니다. 첫 줄은 계정, 두 번째 줄은 초기 비밀번호입니다. 직접 실행은 `data/`, Docker는 영속 볼륨의 `/app/data/`에 있습니다.
3. admin으로 로그인한 뒤 초기 비밀번호를 현재 비밀번호에 입력하고 새로운 비밀번호를 12~256자로 설정합니다.
4. 변경 후 사무실이 열립니다. 초기 비밀번호 파일은 삭제됩니다.

Docker 운영자는 서버 터미널에서 다음 명령으로 초기 파일을 확인할 수 있습니다. 출력은 공유하거나 작업 로그에 첨부하지 마세요.

```bash
docker compose exec office cat /app/data/admin-initial-password.txt
```

## 계정 관리

왼쪽 **비밀번호 변경**에서 현재 비밀번호를 확인하고 새 비밀번호를 저장합니다. 변경하면 다른 로그인 세션은 모두 종료됩니다. **로그아웃**은 현재 로그인만 종료하며 AI 작업을 중지하지 않습니다. 로그인은 8시간 후 만료되고 서버 재시작 시에도 다시 로그인해야 합니다.

비밀번호 해시는 로컬 `admin-auth.json`에 저장합니다. 인증 자료는 업무 DB·인계·Git·이미지에서 제외됩니다. 로그인 실패가 반복되면 15분 동안 재시도가 제한됩니다. 별도 다중 사용자·계정 복구 UI는 제공하지 않습니다. HTTP 접속은 암호화되지 않으므로 인터넷 공개 운영은 HTTPS 배치가 필요합니다.

## 0.1 개발 버전에서 업데이트

기존 직원·업무·대기 메모·검색 사본은 유지됩니다. 업데이트 후 최초로 초기 비밀번호 설정을 진행합니다. 호스트 연결기는 파일 기반 관찰을 계속하며 브라우저 확장은 로그인한 사무실 탭을 통해 기존 방식으로 자료를 전달합니다. 로그인하지 않은 API 호출에는 401을 반환합니다.
