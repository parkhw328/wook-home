# CLI·웹을 직원으로 등록하기

**직원 · 연결 관리**를 펼치면 직원 목록과 **연결 관리 → 감지 / 연결 점검**을 한곳에서 사용할 수 있습니다.

## 감지에서 등록

1. [CLI 연결](CLI.md) 또는 [웹 감지](Detection.md)를 준비합니다. 웹은 연결한 Chrome 프로필의 지원 사이트만 표시합니다.
2. **감지** 탭에서 종류·공급자 필터로 대상을 찾고 **직원 등록·연결**을 누릅니다.
3. **새 직원 등록**을 선택해 이름·역할과 선택 사항인 담당 프로젝트를 입력하거나, 같은 공급자의 **기존 직원**을 선택합니다. 공급자는 감지 대상에 맞춰 지정됩니다.
4. 등록한 직원의 상세에서 연결 상태와 가능한 작업을 확인합니다. 같은 감지 대상은 한 직원에만 연결하며, 등록 후에는 **직원 이름 보기**로 표시합니다.

상단 **직원 채용 → 감지한 CLI·웹으로 등록**에서도 시작할 수 있습니다. 체험 직원과 연결 없는 직원 정보 등록은 기존 채용 양식으로 진행합니다.

## 연결별 가능한 작업

| 연결 | 가능한 작업 |
| --- | --- |
| Codex CLI 대화 기록 | 관찰, 설정된 공개 대화 보기, 호스트가 명시적으로 허용한 경우 **모델·추론 강도 선택과 작업 지시** |
| CLI 실행 프로세스 | 실행·종료 관찰. 대화 연결이 확인되지 않아 지시 전송 불가 |
| 웹 대화 탭 | 열림·닫힘 관찰과 공식 서비스 열기. 메시지는 원래 웹 서비스에서 작성 |
| 웹 서비스·새 대화 화면 | 해당 화면의 열림 관찰. 로그인이나 진행 중인 대화가 확인된 상태가 아님 |

등록 자체로 모델 변경·웹 대화 수집·웹 지시·새 AI 실행 권한이 생기지 않습니다. 같은 계정의 CLI와 웹을 같은 세션으로 합치지 않습니다. 여러 탭에서 같은 웹 대화를 열었다면 한 직원에 탭 수를 함께 표시합니다.

## 담당 프로젝트와 기본 추론 설정

직원 목록의 **프로젝트 · 추론 설정** 또는 직원 상세의 같은 버튼을 누릅니다. 담당 프로젝트 이름을 입력하거나 기존 이름을 선택하고 **변경 사항 저장**을 누르세요. 한 직원의 대표 담당 프로젝트를 지정하며, 입력을 비우면 배정을 해제합니다. 채용할 때에도 입력할 수 있습니다.

목록·방 안 직원·현황 상세에서 담당 프로젝트를 확인합니다. 배정 전이라도 연결된 CLI 대화의 프로젝트가 확인되면 **CLI 작업 · 프로젝트 (배정 미지정)**으로 표시합니다. 상세에서는 담당 프로젝트와 **CLI 작업 프로젝트**를 각각 보여 줍니다. 웹 탭이나 실행 프로세스로 프로젝트를 추정하지 않습니다. 배정을 바꾸어도 기존 CLI의 작업 폴더는 바뀌지 않습니다. 다른 폴더에서 실행하려면 그 프로젝트의 대화를 명시적으로 연결하세요.

지원되는 Codex 직원은 같은 설정 화면에서 기본 모델·강도를 저장할 수 있습니다. 직원별 선택은 로컬 DB에 남으며 새로고침·서버 재시작 후에도 유지됩니다. 저장만으로 지시를 전송하지 않고, 다음 지시 화면에서 기본 선택으로 사용합니다. 개별 지시에서 직접 고른 선택이 있으면 그 초안의 선택을 유지합니다. 실제 모델 변경은 지시를 보낼 때 확인합니다.

다른 창에서 설정이나 연결을 바꾸면 충돌 안내와 함께 작성 내용을 유지합니다. **최신 설정 다시 불러오기**는 미저장 초안을 현재 저장값으로 바꾸므로 필요한 초안을 확인한 후 누르세요. 지원하지 않는 공급자의 모델 제어는 제공하지 않습니다.

## 모델과 작업 지시

직원 상세의 **모델 설정과 작업 지시**에서 모델·추론 강도를 고르고 할 일을 입력합니다. 모델 목록은 실제 Codex 연결에서 가져오며, 선택은 지시 전송 시 다음 실행의 기본값으로 적용합니다. **현재 CLI 설정 유지**도 선택할 수 있습니다. 대화 모달에서는 **직원 정보**로 이동하세요.

OpenAI 직원이 프로세스·웹 관찰 또는 미연결 상태이면 **지시할 Codex 대화 연결**을 눌러 현재 프로젝트의 대화를 명시적으로 선택합니다. 지시 전송이 꺼졌다면 **연결 설정 열기**, 사무실이 중지되었다면 **사무실 업무 재개**를 사용하세요. [모델 선택·적용과 오류 안내](Models.md).

## 변경·해제·다시 연결

- 직원 상세의 **연결 변경·다시 연결**에서 같은 공급자의 다른 감지 대상을 선택합니다. 기존 직원에 연결하면 원래 연결이 교체됩니다.
- **연결 해제**는 직원 정보와 원래 CLI·탭을 그대로 두고 사무실 연결만 해제합니다.
- 탭 닫힘·프로세스 종료와 감지 연결 끊김은 구분하며 직원 정보는 유지됩니다. 새로운 대화 주소는 별도 대상이므로 필요하면 직접 다시 연결하세요.
- 서버·Docker를 재시작하면 **다시 연결 필요**로 표시합니다. 직원 이름·역할·공급자·담당 프로젝트·기본 추론 설정은 저장하지만 감지 식별자와 연결 매핑은 메모리에만 보관하므로 기존 직원을 선택해 재연결합니다.
- 연결이 이미 사용 중이거나 등록 도중 사라졌다면 최신 목록을 확인하세요. 중복 클릭으로 직원을 추가하지 않습니다.

웹 감지 제목·본문·쿠키·로그인 정보를 수집하지 않으며 관찰 정보와 연결 매핑을 Git·배포물·인계 JSON에 포함하지 않습니다. 전체 대상의 상태 진단은 같은 패널의 [연결 점검](Connections.md)을 이용하세요.
