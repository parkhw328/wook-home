# StackQueue Office 빠른 안내

Commander는 직원을 등록하고 업무를 맡긴 뒤, 질문에 답하고 결과를 확인합니다. 처음에는 체험 직원으로 흐름을 익혀 보세요.

## 1. 사무실 열기

Docker Desktop을 실행하고 저장소에서 다음 명령을 입력합니다.

```powershell
docker compose up --build -d
```

http://localhost:8080 에 접속합니다. 기본 사무실 이름은 StackQueue Office이며 `.env`의 `OFFICE_NAME`으로 바꿀 수 있습니다.

## 2. 첫 직원과 업무

1. **직원 채용**에서 이름·역할을 입력하고 **체험 직원**을 선택합니다.
2. 직원 카드나 사무실 캐릭터를 선택해 업무를 지시합니다.
3. Commander 데스크에 나타난 질문에 답하고 결과를 승인합니다.

체험 직원은 실제 AI를 호출하지 않습니다. 외부 공급자 직원을 등록해도 실제 실행·모델 변경은 아직 지원하지 않습니다.

## 3. 기존 Codex 보기

호스트에 Node.js 24.14 이상(27 미만)을 준비한 뒤 별도 터미널에서 실행합니다.

```powershell
npm run bridge:codex -- --workspace .
```

이 프로젝트의 최근 Codex 활동이 사무실 캐릭터와 **이 PC의 CLI 세션**에 나타납니다. 현재는 관찰 전용이며 지시와 중단은 원래 터미널에서 합니다. [연결 범위와 상태의 의미](CLI.md)를 확인하세요.

## 4. 일을 마칠 때

체험 업무는 화면에서 일시 중지하거나 `docker compose stop`으로 상태를 저장합니다. 외부 Codex와 연결 프로그램은 각 터미널에서 별도로 종료합니다. 인계 파일은 내용을 검토한 후 공유하세요.
