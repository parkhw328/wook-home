# StackQueue Office 빠른 안내

Commander는 직원을 등록하고 업무를 맡긴 뒤, 질문에 답하고 결과를 확인합니다. 처음에는 체험 직원으로 흐름을 익혀 보세요.

## 1. 사무실 열기

Docker Desktop을 실행하고 저장소에서 다음 명령을 입력합니다.

```powershell
docker compose up --build -d
```

http://localhost:8080 에 접속합니다. 기본 사무실 이름은 StackQueue Office이며 `.env`의 `OFFICE_NAME`으로 바꿀 수 있습니다.

## 2. 첫 직원과 업무

1. **직원 채용**에서 이름·역할을 입력하고 **체험 직원**을 선택합니다.
2. 입체 건물의 **2F 사무실**에 입장한 뒤 **업무 지시**를 누릅니다.
3. **3F 회의실**에서 질문에 답하고, **대표이사실**에서 업무보고와 대화를 검토해 결과를 승인합니다.
4. **복도로 나오기**로 같은 층의 복도에 퇴실합니다. **1F 휴게실·다과실**도 방문할 수 있습니다. 전체 층과 층별 보기를 전환해 공간을 둘러보세요.

**전체화면**으로 사무실을 넓게 펼치고, 층을 선택해 내부 통로와 가구를 가까이 볼 수 있습니다. **＋ / −**, **화면 맞춤**, **동선 표시**를 사용해 둘러보세요. **업무 패널 ↓**는 선택한 방의 작업 화면으로 이동하며 전체화면을 닫아도 방과 대화 선택은 유지됩니다.

체험 직원은 실제 AI를 호출하지 않습니다. 외부 공급자 직원을 등록해도 실제 실행·모델 변경은 아직 지원하지 않습니다.

## 3. 기존 Codex에 지시하기

호스트에 Node.js 24.14 이상(27 미만)을 준비한 뒤 별도 터미널에서 실행합니다.

```powershell
npm run bridge:codex -- --workspace . --allow-commands --include-conversations
```

이 프로젝트의 최근 Codex 활동이 사무실 캐릭터와 **이 PC의 CLI 세션**에 나타납니다. 세션을 선택해 지시를 보내고 접수 상태를 확인하세요. `codex queue`를 지원하는 CLI가 필요하며 공개 응답은 대화 터미널에서 읽고 승인·중단은 원래 Codex에서 처리합니다. [연결 절차와 문제 해결](CLI.md)을 참고하세요.

## 4. 일을 마칠 때

체험 업무는 화면에서 일시 중지하거나 `docker compose stop`으로 상태를 저장합니다. 외부 Codex와 연결 프로그램은 각 터미널에서 별도로 종료합니다. 인계 파일은 내용을 검토한 후 공유하세요.
