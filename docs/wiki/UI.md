# 사무실 화면 사용법

wook-home은 로컬 서버에 연결해 직원과 업무 상태를 보여줍니다. 현재 외부 AI 연결은 준비 중이며, **체험용 직원**으로 질문·답변·승인 흐름을 사용할 수 있습니다. 체험용 실행은 실제 AI를 호출하지 않습니다.

## 첫 동료와 업무 시작하기

1. 오른쪽 위 **직원 채용**을 누릅니다.
2. 이름과 역할을 입력하고 체험용 공급자를 선택합니다. 모델은 `local-demo`, 추론 강도는 해당 없음으로 표시됩니다.
3. 등록된 직원의 상세 화면에서 **업무 지시**를 누르고 업무 이름과 설명을 입력합니다.
4. 직원의 고정된 안내 질문을 확인하고 답변합니다. 업무는 답변 대기에서 승인 대기로 바뀝니다.
5. 체험용 결과를 검토하고 **결과 승인**을 누르면 완료됩니다.

OpenAI, Claude, Gemini, Meta 직원도 정보 등록은 가능합니다. 아직 연결되지 않은 직원에게는 업무를 지시할 수 없으며, 확인되지 않은 모델 목록이나 추론 옵션은 표시하지 않습니다.

## 사무실과 업무 보드

- 사무실의 책상과 직원 카드는 저장된 직원 정보를 표시합니다. 책상에는 최대 여섯 명이 나타나며 전체 직원은 아래 카드 목록에서 확인합니다.
- 직원이나 업무를 선택하면 역할, 연결 상태, 지원 기능, 대화와 결과를 확인할 수 있습니다. 직원 이름과 역할은 상세 화면에서 수정합니다.
- Commander의 데스크에는 답변과 승인이 필요한 업무가 표시됩니다.
- 업무 보드에서 전체, 응답·승인 대기, 미완료, 완료, 취소된 업무를 구분해 볼 수 있습니다.
- 한 직원에게는 한 번에 하나의 미완료 업무를 맡깁니다. 다른 업무를 시작하려면 기존 업무를 완료하거나 취소합니다.
- 실패, 취소, 일시 중지, 연결 끊김은 완료로 집계하지 않습니다.

화면은 약 2.5초마다 상태를 확인합니다. 서버 연결이 끊어지면 마지막 상태와 연결 오류를 표시하며 변경 작업을 막습니다. 전송 실패한 업무를 자동 재전송하지 않습니다.

## 작업 중지와 인계

1. **작업 인계**에서 **사무실 일시 중지**를 누릅니다. 새 업무와 진행이 멈추고 미완료 상태가 저장됩니다.
2. **인계 기록 다운로드**를 눌러 직원과 업무의 JSON 파일을 받습니다.
3. 대화와 입력 내용이 포함되어 있으므로 파일을 공유하기 전에 내용을 확인합니다.
4. 같은 사무실의 업무를 계속하려면 **사무실 업무 재개**를 누릅니다.

인계 파일 가져오기, 다른 PC의 원래 AI 세션 복원, GitHub 자동 전송은 지원하지 않습니다. 사무실 재개는 현재 저장소에 보관된 체험 업무를 이어가는 기능입니다.

## 키보드와 작은 화면

탭 키로 탐색 메뉴, 직원 카드, 입력 항목과 버튼을 이동합니다. 첫 링크인 **본문으로 이동**으로 탐색 메뉴를 건너뛸 수 있습니다. 대화상자는 Escape 또는 닫기 버튼으로 닫습니다. 저장 요청을 처리하는 동안에는 중복 전송과 닫기를 잠시 막습니다.

작은 화면에서는 탐색 메뉴가 위쪽으로 이동하고 카드가 세로로 배치됩니다. 아래쪽 프로그램 카드의 GitHub 링크는 새 탭에서 열립니다.

## 문제 해결

- **서버 연결 끊김**: 로컬 서버 실행 상태와 접속 주소를 확인하고 **다시 연결**을 누릅니다.
- **업무 지시가 비활성화됨**: 체험용 직원인지, 진행 중 업무가 있는지, 사무실이 중지되었는지 확인합니다.
- **답변을 입력할 수 없음**: 업무가 답변 대기인지 확인합니다. 승인 대기에는 결과 승인 버튼이 표시됩니다.
- **새로고침 후 입력 내용이 사라짐**: 전송하지 않은 입력은 저장되지 않습니다. 전송된 대화와 직원 정보는 서버에 보관됩니다.

## 개발 검증

화면은 `public/index.html`, `public/styles.css`, `public/app.js`로 구성하고, 상태 판정과 요청 처리는 `public/model.mjs`, `public/api.mjs`에서 관리합니다. 외부 UI 라이브러리와 빌드 단계는 필요하지 않습니다.

상태 판정, 실행 가능 조건, 입력 문자열 처리, 프로그램 링크 제한, 네트워크 오류와 중복 재시도 방지는 `tests/ui/*.test.mjs`에서 검증합니다.

```sh
node --test tests/ui/*.test.mjs
```
