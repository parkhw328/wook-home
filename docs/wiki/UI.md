# StackQueue Office 화면 사용법

프로젝트별 전용 층을 가진 입체 사무실에서 동료를 만나 보세요. Commander가 엘리베이터와 복도를 거쳐 방에 입장하면 그 공간의 직원·세션·업무와 대화기록을 확인할 수 있습니다.

## 왼쪽 탐색과 링크

왼쪽 탐색 영역 맨 위 카드에서 **현재 사용자** Commander와 역할, 서버 연결 상태를 함께 확인합니다. **admin** 영역을 누르면 **비밀번호 변경·로그아웃** 메뉴가 열립니다. Enter·Space로 열고 Tab으로 항목을 선택하며 Escape·메뉴 바깥 선택으로 닫을 수 있습니다. 같은 카드 아래쪽에는 사무실 이름과 홈으로 가는 링크가 있습니다.

**프로그램 · 블로그**를 펼치면 StackQueue Blog·wShell·wPost·wText의 아이콘, 한 줄 소개와 외부 링크가 보입니다. 블로그 이름은 한 줄로 표시하며, wPost는 **API 요청·응답**, wText는 **문서 편집·비교**로 소개합니다. 링크는 새 탭으로 열립니다.

하단 **도움말**은 이 사용설명서로, **버전 번호**는 현재 버전의 변경 이력으로 바로 연결됩니다. 별도의 화면 사용법 항목이나 중복 도움말 메뉴는 없습니다.

작은 화면에서는 프로그램 목록이 접힌 상태로 시작합니다. 제목을 누르거나 Tab으로 선택한 뒤 Enter·Space로 펼칠 수 있습니다. 자동 갱신은 펼침 상태와 선택한 링크 초점을 유지합니다. 화면 높이가 짧으면 왼쪽 영역을 스크롤해 나머지 링크를 확인하세요.


## 라이트·다크 테마

왼쪽 **화면 테마**에서 **라이트**, **다크**, **기기 설정**을 선택합니다. 첫 방문은 기기 설정을 따르며, 직접 고른 테마는 홈·직원과 연결 관리·업무 보드·자료 검색·작업 인계·모든 대화상자에 즉시 적용됩니다. 사무실의 배경과 조명도 함께 바뀝니다. 전체화면에서는 장면 조작 줄의 **화면 테마**를 사용하세요.

선택은 현재 브라우저에 저장되어 새로고침 후에도 유지되고, 같은 서버 주소를 연 다른 탭에도 반영됩니다. 다른 브라우저·기기·서버 주소에는 따로 설정합니다. 브라우저가 저장을 차단해도 현재 탭에서는 변경할 수 있습니다. **기기 설정**을 선택한 동안에는 운영체제의 밝은/어두운 모드 변경을 따라갑니다.

테마를 바꿔도 선택한 방·직원·세션·검색 조건·작성 중인 내용과 읽던 대화 위치는 유지됩니다. 테마 선택은 Tab과 방향키로도 조작할 수 있습니다.

## 버튼과 선택 상태

버튼과 카드·대화창·알림·장면 이름표는 그림자 없는 평면형으로 표시합니다. 눌렀을 때는 배경색과 테두리색이 바뀌며, 선택과 키보드 초점은 선과 글씨 굵기로 구분합니다. 라이트·다크와 전체화면에도 같은 형태를 적용합니다.

진한 빨강 버튼은 **실행·저장·전송·승인**에 사용합니다. 이동·새로고침·닫기는 중립색 테두리로, 도움말은 밑줄 링크로 표시합니다. **일시중지·연결 해제**는 황토색, **업무 취소**는 빨간 글씨와 테두리로 구분합니다. 재개할 수 있게 되면 버튼도 진한 빨강으로 바뀝니다.

선택된 층·방·탭과 켜진 토글에는 굵은 글씨와 선이 함께 표시됩니다. 회색 버튼은 현재 사용할 수 없는 상태입니다. Tab 키로 이동하면 파란 외곽선으로 현재 버튼을 확인할 수 있으며 Enter 또는 Space로 실행합니다. 버튼 높이는 최소 44px, 일반 버튼 글씨는 최소 16px를 유지합니다.

## 상세창 열기와 닫기

CLI 대화·직원 정보·직원 연결·검색 결과는 한 번에 하나의 창으로 열립니다. 위쪽 **닫기 ×**는 본문을 아래로 읽어도 같은 자리에 남습니다. **Escape** 또는 창 바깥의 어두운 영역을 눌러도 닫을 수 있으며, 원래 선택한 항목으로 키보드 초점이 돌아갑니다. 창 안에서 드래그를 시작했다면 바깥에서 놓아도 닫히지 않습니다.

**연결 설정**이나 **전체 자료 검색**으로 이동하면 상세창도 닫힙니다. 전체화면에서도 같은 조작을 사용할 수 있습니다. 닫기는 화면만 닫으며 CLI 실행·이미 보낸 지시·저장 요청을 취소하지 않습니다. 전송 중에도 창을 닫을 수 있고 접수 상태는 다시 열어 확인할 수 있습니다. CLI 검색 조건·읽던 위치와 지시 초안, 채용·직원 수정·체험 업무 양식은 현재 탭에서 다시 열 때 유지됩니다. 새로고침 후 미전송 초안 복원은 지원하지 않습니다.

방 아래 작업 패널은 체험 업무보고와 답변을 위한 영역입니다. **화면 닫기 ×**로 보고를 접고 **업무보고 다시 열기**로 돌아갈 수 있습니다. CLI 대화기록은 이 패널에 중복 표시하지 않습니다. 자동 갱신이 접은 패널을 다시 펼치지 않습니다.

## 간결한 탐색과 계정 관리

맵 하단은 층 번호·방 아이콘으로 표시하며, 0.2.2부터 여유 폭 안에서 가운데 정렬합니다. **마우스 올림·키보드 초점**으로 프로젝트와 방의 전체 이름을 확인하세요. 방향키·Home·End로 이동하고 Enter·Space로 선택할 수 있습니다. 작은 화면에서는 줄 안을 좌우로 스크롤하며, 터치로 한 번 누르면 방에 입장하면서 전체 이름도 표시합니다. Escape는 열린 이름 안내부터 닫습니다.

**움직임 켜짐/꺼짐**은 맵 상단 오른쪽에 다른 조작과 간격을 두고 배치합니다. 캐릭터의 장식 움직임을 조절하며 시스템의 동작 줄이기 설정을 따릅니다. CLI 감지 설정은 **연결 설정**에서 확인합니다.

로그인·업무 보드·검색·인계·연결 관리·상세창의 간격을 공통으로 줄였습니다. **연결 설정**은 본문 전체 폭을 사용하며 감지·연결 점검·설정 탭 사이에서 선택과 작성 내용을 유지합니다. 좁은 화면에서는 주 탐색 메뉴가 한 줄로 스크롤됩니다.

상단 **admin → 비밀번호 변경**은 사무실 안에서 모달로 열립니다. 기존과 다른 8~256자로 변경하고 완료 안내를 확인하세요. 닫을 때 입력 비밀번호는 지워지고 상단 계정 버튼으로 초점이 돌아갑니다. 자세한 내용은 [관리자 로그인](Login.md)을 참고하세요.

## 사무실 둘러보기

**첫 화면은 활성 프로젝트의 업무층이며, 활성 프로젝트가 없으면 1층 대기실**입니다. 0.2.4부터 활성 연결이 없는 업무층은 숨기고 공용 라운지와 대표이사실만 유지합니다. 층이 사라지면 현재 위치를 대기실로 정리하며, 남아 있는 방·입력 초안·확대·전체 건물 보기는 유지합니다. 맵 하단에서 방을 선택하면 해당 층으로 이동합니다. **전체 건물**은 모든 프로젝트 층을 함께 보여 줍니다. 이 버튼은 보기만 바꾸며 현재 방과 업무 선택을 유지합니다. 같은 방 버튼을 다시 누르면 해당 층 보기로 돌아갑니다. 오른쪽은 방 설명과 업무 목록으로 사용합니다. 넓은 화면에서는 맵과 방 설명 패널의 위아래 높이를 맞춥니다. 작은 화면에서는 내용 높이에 따라 차례로 쌓입니다.

**Commander의 데스크**와 **사무실 소식**은 맵·업무보고 아래의 독립 구역에 있습니다. **직원 · 연결 관리**를 접어도 읽을 수 있고, 데스크에서 응답이 필요한 업무를 열거나 **업무 보드에서 모두 보기**로 이동할 수 있습니다. 넓은 화면은 두 카드를 나란히, 작은 화면은 세로로 표시합니다.

**라이트 모드에서는 낮, 다크 모드에서는 밤의 사무실**이 펼쳐집니다. 낮에는 밝은 하늘과 자연광이, 밤에는 도시 불빛과 따뜻한 실내등이 보입니다. 실제 시각과 관계없이 선택한 테마를 따르며, **기기 설정**은 기기의 라이트·다크 선택에 맞춥니다. 모든 층과 전체화면에 함께 적용되고 테마를 바꿔도 선택한 층·방·확대와 작성 중인 내용은 유지됩니다.

**＋ / −**로 장면을 확대·축소하고 **맞춤**으로 전체를 다시 담습니다. 이름표의 글자 크기는 유지합니다. **동선**는 청록색 점선 통로 안내와 밝은 실선 이동 경로를 켜거나 끕니다. 직원은 책상 열 사이 통로와 문을 지나 복도로 나옵니다.

**전체화면**은 사무실을 넓게 펼칩니다. 브라우저가 전체화면을 허용하지 않으면 브라우저 안에서 넓은 보기로 전환합니다. 선택한 방·세션·검색·작성 중인 대화는 유지되며 **업무 ↓**로 아래 작업 화면에 바로 갈 수 있습니다. **전체화면 닫기** 또는 Escape로 일반 화면에 돌아옵니다.

입체 장면이나 장면 아래의 층 번호·방 아이콘 버튼에서 목적지를 선택합니다. Commander는 현재 방의 문으로 나와 복도를 따라 이동하고, 다른 층은 엘리베이터를 거친 뒤 목적지 문으로 들어갑니다. 이동 중 다른 방을 선택하면 현재 이동을 마친 뒤 마지막으로 선택한 방으로 이동합니다.

| 층 | 공간 | 하는 일 |
| --- | --- | --- |
| 최상층 · 공용 | 대표이사실 | Commander 질문·발표, 업무보고, 결과 검토·승인, 완료·실패·중단 기록 확인 |
| 프로젝트별 전용 층 | 사무실 | 직원 선택, 업무 지시, 기존 Codex 세션의 지시·응답 확인 |
| 프로젝트별 전용 층 | 회의실 | 협업한 직원·세션의 논의 동작과 관련 대화 확인 |
| 1F | 휴게실 | 새 업무를 기다리는 직원 확인 |
| 1F | 대기실 | 보관 업무·메모, 생존 미확인·연결 소실 직원 확인 |
| 1F | 다과실 | 오프라인 작업 히스토리·프로젝트 필터·지난 대화 읽기 |

**현재 위치**에 층과 방을 표시하고 선택한 방의 작업 패널이 함께 바뀝니다. **복도로 나오기**는 같은 층의 복도로 퇴실합니다. 이동은 화면의 위치만 바꾸며 실제 CLI 실행을 중단하거나 업무를 완료하지 않습니다. 입체 캐릭터는 실제 등록 직원·관찰 세션만 표현하며 업무 상태에 따라 공간을 옮깁니다. 책상 동작과 짧은 복도 보행은 공간 표현이며 실제 업무 상태는 선택한 동료의 상태로 확인합니다. 화면에 모두 배치할 수 없는 인원도 공간의 목록과 **직원 · 연결 관리**에서 빠짐없이 선택할 수 있습니다.

## 숫자에서 세부정보 확인하기

방 아래의 **사무실 전체 현황** 카드는 어느 방에서나 누를 수 있습니다. 카드의 인원·건수와 같은 기준으로 목록이 열립니다. 현재 방에 있는 사람 수는 장면의 방 이름 옆 숫자로 구분합니다.

| 카드 | 목록과 다음 행동 |
| --- | --- |
| 직원 | 등록된 전체 직원. 이름을 누르면 역할·연결 상태·맡은 업무를 확인합니다. 미등록 CLI 세션은 직원 수에 포함하지 않습니다. |
| 진행 업무 | 접수·실행 중과 답변·승인 대기를 포함합니다. 항목을 누르면 해당 방으로 이동하고 업무보고가 화면에 나타납니다. |
| 응답·승인 | Commander의 답변 또는 결과 승인을 기다리는 업무와 보고 화면으로 연결합니다. |
| 완료 업무 | 완료 처리된 업무의 결과·대화를 다시 확인합니다. 실패·취소·일시 중지는 포함하지 않습니다. |

0명·0건도 눌러 빈 목록 안내를 볼 수 있습니다. 목록은 자동 갱신되며 읽던 위치와 선택한 항목의 키보드 초점을 유지합니다. 서버가 끊기면 마지막 수신 목록임을 표시합니다. Tab과 Enter·Space로 열고 Escape 또는 닫기 버튼으로 닫으면 원래 현황 카드로 돌아갑니다.

## 첫 업무부터 보고까지

1. **직원 채용**에서 이름·역할과 **체험 직원**을 선택합니다. 모델은 `local-demo`입니다.
2. **사무실**에 들어가 **업무 지시**를 누르고 담당 직원·업무 이름·설명을 입력합니다.
3. 질문이 준비되면 **대표이사실**로 이동하고 직원이 발표 화면 앞에서 설명하는 동작을 합니다. 화면 아래의 질문을 읽고 **답변 보내기**를 누릅니다.
4. **대표이사실**로 이동해 목표, 담당 직원, 보고된 결과와 대화를 함께 검토합니다.
5. **보고 확인 · 결과 승인**을 누르면 완료됩니다. 취소·실패·일시 중지는 완료로 집계하지 않습니다.

체험 직원은 실제 AI를 호출하지 않으며 고정된 안내와 결과로 흐름을 보여 줍니다. OpenAI·Claude·Gemini·Meta 직원 정보 등록과 실제 외부 AI 실행 지원은 구분합니다. 한 직원에게 한 번에 하나의 미완료 업무를 맡길 수 있습니다.

지원되는 실제 세션 간 협업은 **회의실**의 논의 동작으로, 구조화된 질문·승인은 **대표이사실**의 발표로 표시합니다. 단발성 협업은 최근 이벤트이며 웹 탭의 작업 내용을 추정하지 않습니다. 표시 시간과 지원 범위는 [협업·발표 안내](Activity.md)를 참고하세요.

## CLI 대화 모달

[CLI 연결 안내](CLI.md)에 따라 연결기를 실행한 뒤 CLI 세션 목록·캐릭터·방 안의 세션이나 연결된 직원을 누르면 대화 모달이 바로 열립니다. 방에 입장할 때 첫 CLI 기록을 하단에 자동으로 열지 않습니다. 대화를 읽어도 현재 방·화면 위치·작성 중인 업무 답변은 그대로 유지됩니다. 카드에 마우스를 올리면 전체 세션 ID가 나타납니다. 키보드 초점이나 상세창의 **ID** 버튼으로도 확인할 수 있습니다. **이 세션에 지시**를 누르면 별도 지시 입력과 접수 상태가 열립니다.

대화기록은 **연결 설정 → 공개 대화 읽기 → 설정 저장** 후 적용되면 표시합니다. 꺼진 대화창의 **대화 · 지시 설정**으로 바로 이동할 수 있습니다. 사용자 지시와 공개된 에이전트 응답을 시간순으로 보여 주며, **세션 · 검색 · 작성자 필터**와 **최신 기록**으로 원하는 내용을 찾습니다. 작은 화면에서는 필터를 접어서 대화 공간을 확보하며 제목을 눌러 펼칩니다. 체험 업무의 대화는 체험 응답임을 별도로 표시합니다.

- 화면은 약 2.5초마다, 호스트 연결기는 약 5초마다 갱신합니다. 자동 갱신 중 선택한 방·세션·검색·작성 중인 답변과 지시·읽던 스크롤을 보존합니다.
- 최신 위치에서 읽고 있었다면 새 기록을 따라갑니다. 이전 내용을 읽는 동안에는 임의로 맨 아래로 이동하지 않습니다.
- 최근 기록 범위, 수신 시각, 잘림 여부를 터미널에 표시합니다. 전체 대화 보관함이나 원래 CLI의 완전한 재현은 아닙니다.
- 연결이 꺼져 있으면 활성화 안내, 공개 대화가 없으면 빈 기록, 갱신이 멈추면 연결 끊김과 마지막 수신 내용이 표시됩니다. 예시 대화를 실제 기록처럼 만들지 않습니다.
- 시스템·개발자 지침, 내부 추론, 도구 원문은 제외합니다. 알려진 인증 정보·개인 경로 등을 마스킹하지만 임의의 모든 민감 문장을 판별하는 기능은 아닙니다.
- 대화 본문을 HTML로 실행하지 않습니다. 로컬 CLI 기록은 Git, 이미지, 인계 JSON으로 내보내지 않습니다.

**Codex 큐 접수는 업무 완료가 아닙니다.** 실제 승인·중단은 원래 Codex에서 처리합니다. [모델·추론 강도](Models.md)는 직원 상세 또는 지시 화면에서 선택하며 다음 실행부터 적용합니다. 응답 유실 시 접수 기록만 조회하고 자동으로 지시를 다시 보내지 않습니다. 같은 탭에서 새로고침하면 지시 ID와 세션 ID만 복원하며 전송 원문·작성 중인 초안은 브라우저에 저장하지 않습니다.

## 연결 관리와 업무 보드

**직원 · 연결 관리**를 펼치면 직원 목록과 **감지 / 연결 점검** 탭을 함께 사용할 수 있습니다. 감지 항목에서 **직원 등록·연결**을 누르면 새 직원을 등록하거나 같은 공급자의 기존 직원에 연결합니다. 직원 상세에서 연결 변경·해제, 지원되는 CLI의 대화·지시 화면, 웹 서비스 열기를 이용할 수 있습니다. 현재 프로젝트의 살아 있는 Codex 세션은 자동 등록하고 같은 직원으로 재연결합니다. **별칭 · 직원 설정**에서 이름을 저장하며 전체 session-id는 카드·ID 버튼의 마우스 올림 또는 키보드 초점으로 확인하며 터치에서는 상세창의 ID 버튼을 누릅니다. 미등록 대상은 별도 등록 대기 목록에서 직접 등록합니다. 웹·CLI 프로세스는 관찰 전용이며 재시작 후 직접 다시 연결합니다. [직원 연결 안내](Staff.md), [CLI 안내](CLI.md), [감지 안내](Detection.md), [전체 연결 점검](Connections.md)을 참고하세요.

공식 서비스 열기 링크는 각 사이트에서 로그인하는 용도입니다. 외부 사이트 로그인만으로 대화 본문이나 실행 제어가 사무실에 연결되지는 않습니다. [공급자 안내](Providers.md)에서 지원 범위를 확인하세요.

**업무 보드**에서는 전체·응답/승인 대기·미완료·완료·취소 상태로 업무를 찾습니다. 업무를 선택하면 해당 업무를 처리할 방과 보고 화면으로 이동합니다. 직원 이름과 역할은 상세 화면에서 수정합니다.

## 작업 중지와 인계

**작업 인계 → 사무실 일시 중지**로 체험 업무와 새 지시 접수를 멈추고 상태를 저장합니다. 외부 CLI 자체는 중지되지 않습니다. **인계 기록 다운로드**에는 체험 직원·업무·입력 내용이 포함되므로 공유 전 내용을 검토하세요. 실제 CLI 대화기록은 제외됩니다. 인계 가져오기·다른 PC 세션 복원·GitHub 자동 전송은 준비 중입니다.

## 키보드와 작은 화면

Tab으로 이동하고 Enter 또는 Space로 방에 입장합니다. 방 선택 줄에서는 좌우 방향키와 Home/End로 목적지 버튼을 이동합니다. 전체화면의 Escape는 보기 종료이며 방을 나가지 않습니다. 일반 방 화면의 Escape는 복도로 나오기이며, 대화상자 안에서는 닫기로 동작합니다. 입력 중 Escape로 방을 바꾸지 않습니다.

작은 화면에서도 맵 하단의 방·전체 건물 버튼은 한 줄을 유지하며 좌우 스크롤이나 방향키로 찾습니다. 움직임 버튼은 맵 상단 오른쪽에 있으며, 현재 위치·동선 설명은 하단 버튼 다음 줄에서 가로로 스크롤합니다. 작업 패널과 터미널은 세로로 배치됩니다. 입체 장면은 좌우로 스크롤할 수 있으며 방 이름 버튼으로도 동일하게 이동합니다. 텍스트는 원근 변환하지 않습니다. 장면에서 줄인 이름은 캐릭터의 접근성 이름과 전체 목록에서 확인할 수 있습니다.

**움직임 켜짐/꺼짐**과 운영체제의 동작 줄이기를 지원합니다. 동작 줄이기에서는 경로 애니메이션 없이 목적지에 도착하며 업무 기능은 같습니다. 한글은 Noto Sans KR, 영문·숫자는 JetBrains Mono를 앱에서 직접 제공합니다.

## 글자 크기와 읽기

왼쪽 탐색 영역 최상단에는 현재 사용자·역할과 로컬 서버 연결 상태가 함께 표시됩니다. 바로 아래의 로고·사무실 이름을 누르면 사무실로 돌아옵니다. 같은 정보를 반복하던 본문 상단 바와 별도 워크스페이스 카드는 없으며 작은 화면에서도 사용자와 연결 상태가 먼저 보입니다. 현재 메뉴는 왼쪽의 선택 표시와 본문 제목으로 구분합니다.

한글·영문·숫자는 같은 용도에 같은 크기를 사용합니다. 브라우저 기본 설정에서 본문과 대화는 17px, 메뉴·버튼·입력창은 16px, 안내는 15px, 상태·시각·버전은 최소 14px, 구역 제목은 22px입니다. 좁은 화면에서는 줄바꿈과 열 배치를 바꾸고 글자를 줄이지 않습니다. 브라우저의 글꼴 크기와 확대 설정도 사용할 수 있습니다.

## 내 도구들

wShell·wPost·wText 카드에는 각 앱에서 사용하는 실제 아이콘을 표시합니다. 아이콘과 프로그램 이름으로 도구를 구분하고, 카드를 누르면 해당 GitHub 저장소가 새 탭에서 열립니다. 작은 화면에서도 아이콘 크기와 프로그램 이름의 가독성을 유지합니다.

## 문제 해결

- **서버 연결 끊김**: 로컬 서버를 확인하고 다시 연결합니다. 마지막 상태는 읽을 수 있으나 변경 버튼은 비활성화됩니다.
- **업무 지시 비활성화**: 체험 직원의 존재, 진행 중인 업무, 사무실 중지 여부를 확인합니다.
- **CLI 기록이 없음**: **연결 설정 → 공개 대화 읽기**의 적용 상태, 프로젝트·세션 일치 여부와 최근 기록 범위를 확인합니다.
- **CLI 지시 비활성화**: **연결 설정 → Codex 지시 전송**의 적용 상태, 관찰 연결, 사무실 중지 여부를 확인합니다.
- **실행 상태와 공간이 다름**: 공간 이동과 실제 프로세스 실행은 서로 다른 상태입니다. CLI 턴 종료도 사무실 업무 승인 완료를 뜻하지 않습니다.
- **입체 화면을 표시할 수 없음**: 브라우저의 WebGL 2 사용 가능 여부를 확인합니다. 위의 층·방 목록과 업무·대화기록은 계속 사용할 수 있습니다.

## 방 안내와 목록

넓은 화면은 방 안내 폭을 360~440px로 확보합니다. 별도의 층 둘러보기 영역 없이 방 설명과 목록을 바로 표시하며 목록에 최대 768px까지 공간을 제공합니다. 작은 화면에서는 지도 아래에 방 설명과 목록을 배치해 중첩된 세로 스크롤 없이 읽을 수 있습니다.

살아 있는 등록 직원은 턴 종료 후에도 사무실에 남으며 연결 소실·생존 미확인 직원은 1층 대기실에서 확인합니다. 미등록 세션은 직원·캐릭터 수와 분리한 등록 대기 목록에 표시합니다. 사무실 목록과 캐릭터는 같은 배치 기준을 사용합니다. 이는 실제 CLI 종료 판정이나 자동 업무 보관이 아니며, 대화 확인·새 지시·명시적 보관은 계속 이용할 수 있습니다. 유효한 질문·승인 요청과 최근 협업은 해당 공간에 표시합니다.

맵 하단의 방 이동 버튼은 **최상층 대표이사실 → 프로젝트별 사무실·회의실 → 1층 휴게실·대기실·다과실** 순서로 표시합니다.

맵 하단은 방·층 이동을 한 줄로, 현재 위치·동선 설명을 다음 한 줄로 표시합니다. 좁은 화면에서는 각각 가로로 스크롤할 수 있습니다. 움직임 버튼은 상단 오른쪽에 있습니다.

현재 버전의 [프로젝트 층·작업 히스토리](Projects.md)와 [로그인·비밀번호 변경](Login.md)을 참고하세요.
