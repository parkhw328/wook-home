# wook-home 사용설명서

여러 AI 에이전트를 직원처럼 모아 업무를 지시하고 결과를 확인하는 가상 회사입니다. 사용자는 Commander로서 업무 우선순위와 최종 판단을 담당합니다.

## 현재 상태

현재는 설계 단계입니다. 이 Wiki는 저장소에서 관리하는 사용설명서 초안이며, 실행 가능한 앱·설치 파일·Docker 이미지는 아직 없습니다. GitHub Wiki 탭 게시와는 별도로 관리됩니다.

## 예정된 사용 흐름

1. 작업 PC에서 Docker 환경을 실행하고 로컬 웹 화면에 접속합니다.
2. 공급자 연결을 설정하고 직원을 새로 등록하거나 지원되는 기존 세션을 연결합니다.
3. 직원에게 업무를 지시하고 질문에 답하며 결과를 확인합니다.
4. PC를 옮길 때 작업을 중지하고 코드와 인계 내용을 GitHub에 반영합니다.
5. 다른 PC에서 변경 내용을 가져와 업무를 이어갑니다.

OpenAI, Claude, Meta Muse, Google Gemini 연결을 준비합니다. 실제 지원 제품과 기능은 구현·검증 후 안내합니다. 기존 세션 연결 범위는 공급자마다 다를 수 있습니다.

## 시작 방법과 문제 해결

설치 전제 조건, 인증 설정, 실행 명령, 접속 주소와 오류 해결 절차는 실제 환경 검증 후 추가합니다. 현재 안내할 실행 명령은 없습니다.
