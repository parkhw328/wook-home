# 협업 회의와 Commander 프레젠테이션

사무실의 직원과 CLI 캐릭터는 확인된 업무 상태에 맞춰 이동합니다. 공간 동작은 실제 메시지 전송이나 승인을 대신하지 않습니다.

## 회의실에서 협업 확인

지원되는 Codex 세션이 같은 프로젝트의 다른 세션에 협업 메시지를 전달하면 참여한 캐릭터가 문·복도·엘리베이터를 거쳐 회의실로 이동합니다. 테이블에서 서로를 바라보며 논의하는 동작을 보여 줍니다.

단발성 메시지 전달은 **최근 협업**으로 최대 60초 표시합니다. 계속 회의 중임을 추정하지 않으며, 새 협업 이벤트가 확인되면 갱신합니다. 회의실 목록에서 참여 세션의 대화를 선택할 수 있습니다.

## 대표이사실에서 질문과 발표 확인

- 체험 직원의 질문과 결과 승인은 대표이사실에서 답변하거나 처리합니다.
- Codex의 구조화된 질문·승인 요청이 관찰되면 해당 캐릭터가 대표이사실의 발표 화면 앞에서 설명하는 동작을 합니다.
- 실제 Codex 질문의 선택지 답변과 실행 승인은 원래 Codex 창에서 처리하세요. 사무실의 지시 전송은 공급자의 승인 인터페이스를 대신하지 않습니다.
- 질문은 응답·턴 종료·중단 시 해제합니다. 응답 이벤트를 확인할 수 없으면 최대 30분 뒤 표시를 해제하며 계속 대기 중이라고 단정하지 않습니다.

## 준비와 표시 범위

[CLI 연결](CLI.md)의 연결 프로그램을 최신 코드로 다시 실행하면 활동 종류가 전달됩니다. **연결 설정**의 지시 전송과 공개 대화 읽기는 별도 선택입니다. 활동 감지만으로 권한은 늘어나지 않습니다.

현재 확인한 협업 경로는 Codex 앱의 세션 간 메시지 전달 도구이며, 질문은 구조화된 사용자 입력 요청입니다. 일반 문장의 물음표, 추론 내용, 단순한 웹 탭 열림으로 회의·질문을 추정하지 않습니다. 웹 직원과 지원되지 않는 CLI는 기존 관찰 범위를 유지합니다.

직원에 연결한 CLI는 하나의 캐릭터로 표시합니다. 연결이 끊기거나 활동이 만료되면 논의·발표 동작을 해제합니다. **움직임 끄기**나 동작 줄이기 설정에서는 이동·손짓을 생략하고 목적지와 상태를 바로 표시합니다. 캐릭터 자동 이동은 Commander의 방 선택·카메라·대화 초안을 바꾸지 않습니다.

원문 대화와 도구 인수는 활동 표시로 전송하지 않습니다. 활동 종류·시각·같은 프로젝트의 참여 세션 ID만 일시적으로 사용하며 검색 보관·Git·인계에 포함하지 않습니다.
