# CLI와 웹 대화 자료 검색

왼쪽 **자료 검색**에서 진행 중인 세션과 보관한 지난 대화의 메시지를 찾습니다. 한글·영문 검색과 CLI/웹, 공급자, 작성자, 기록 상태 필터를 함께 사용할 수 있습니다. 결과를 누르면 일치 문장과 앞뒤 대화가 모달에 열립니다. 웹 자료는 **원본 대화 열기**로 돌아갈 수 있습니다.

CLI 목록·직원 캐릭터·방 안의 CLI 세션을 클릭하면 **대화기록 모달**이 즉시 열립니다. 아래로 스크롤할 필요 없이 세션을 전환하고 검색·역할 필터·최신 기록·지시 화면을 이용하세요. 닫았다 다시 열면 해당 세션의 검색 조건과 읽던 위치를 유지합니다. 위쪽 **닫기 ×**, Escape 또는 창 바깥 클릭으로 돌아갑니다. 닫기 버튼은 본문을 스크롤해도 보이며 CLI 실행은 계속됩니다. 작은 화면에서는 **세션 · 검색 · 작성자 필터**를 펼쳐 조건을 바꿉니다.

## CLI 기록 연결

**자료 검색 → CLI 검색 보관 설정** 또는 왼쪽 **연결 설정**에서 **CLI 대화 검색 보관**을 켜고 저장하세요. 연결기 실행 대기라면 화면의 명령을 서버 PC의 저장소 터미널에서 실행합니다. [처음 연결과 업데이트](CLI.md)를 참고하세요.

- **공개 대화 읽기**: 최근 Codex 메시지를 모달에서 읽는 별도 선택입니다.
- **CLI 대화 검색 보관**: 선택 프로젝트의 Codex·Claude Code·Gemini 저장 기록을 약 30초마다 검색용으로 읽습니다. 오래된 기록과 Codex의 archived_sessions도 찾으며 원래 로그는 수정하지 않습니다.
- **Codex 지시 전송**: 검색만 필요하면 켜지 않아도 됩니다.

화면에서 해제하고 저장하면 새 수집을 멈춥니다. 탭 닫힘·연결기 종료·재시작 뒤에도 기존 검색 사본은 남습니다.

Codex는 `CODEX_HOME` 또는 기본 `.codex`, Claude Code는 `CLAUDE_CONFIG_DIR` 또는 기본 `.claude/projects`, Gemini CLI는 기본 `.gemini/tmp`의 프로젝트 해시 아래 chats를 확인합니다. 본문의 작업 폴더 또는 프로젝트 해시가 정확히 일치하는 기록만 포함합니다. 다른 프로젝트나 계정의 전체 기록을 합치지 않습니다. 공급자의 저장 형식이 바뀌거나 로컬 기록이 없으면 검색할 수 없습니다.

수집 회차당 최근 수정된 최대 500개 대화, 대화당 최근 1000개 메시지·50만 자, 메시지당 2만 자를 보관합니다. 128MB가 넘는 JSONL, 8MB가 넘는 Gemini JSON은 건너뜁니다. 생략·읽기 실패는 보관함 상태에 표시합니다. 기존 검색 사본은 연결기를 끄거나 CLI가 종료되어도 유지됩니다.

## 웹 대화 선택

1. [감지 확장프로그램](Detection.md)을 설치합니다. 저장소를 업데이트했다면 버전 번호가 같아도 `chrome://extensions`의 **StackQueue 웹 탭 감지 → 새로고침**으로 최신 파일을 적용하고, 열려 있는 사무실과 AI 탭도 새로고침합니다.
2. 보관할 ChatGPT·Claude·Gemini·Meta AI **대화 탭**에서 확장 버튼을 엽니다.
3. **현재 대화 보관 켜기**를 누릅니다. 새 대화·홈페이지는 저장된 대화 주소가 생긴 뒤 선택합니다.
4. 확장을 설치한 PC에서 `http://localhost:8080` 사무실의 **자료 검색 → 웹 보관 켜기**를 누릅니다. 원격 IP·호스트 주소에서는 현재 확장의 자동 수집을 지원하지 않습니다. 아래 직접 보관과 기존 자료 검색을 사용할 수 있습니다.

선택한 대화에서 화면에 불러온 사용자 메시지·공개 답변을 약 10초마다 읽습니다. 보관을 켠 다른 대화도 함께 수집하며 중복 탭은 하나로 처리합니다. 사무실이 열려 있지 않거나 브라우저가 백그라운드 작업을 제한하면 수집되지 않거나 늦어집니다. 닫기 전에 **보관함 새로고침**과 수집 상태를 확인하세요.

같은 AI 탭에서 다른 대화로 이동하면 해당 대화의 보관 선택을 다시 확인합니다. 수집 중 대화가 바뀌거나 개별 보관을 끄면 진행하던 수집 결과를 보내지 않으며, 다른 대화 본문을 이전 대화에 이어 저장하지 않습니다.

보관한 자료는 탭을 닫은 뒤에도 남습니다. 이전에 수집하지 않은 닫힌 대화는 다시 열고 보관을 켜야 합니다. 화면에 로드되지 않은 과거 메시지, 첨부파일 내부, 로그인 뒤 계정 전체 기록을 자동으로 내려받지 않습니다. 페이지 구조가 지원되지 않으면 **읽지 못함**으로 표시하며 페이지 전체 본문으로 대신 수집하지 않습니다. **공개 대화 텍스트 직접 보관**에 원하는 자료를 붙여 넣을 수도 있습니다.

확장에서 개별 대화 보관을 끄거나 사무실의 **웹 보관 끄기**로 새 수집을 중지합니다. 기존 검색 사본은 유지합니다. 시크릿 탭은 제외하며 프로필당 최대 50개 대화를 선택할 수 있습니다.

## 공개 텍스트 직접 보관

확장 연결이 없거나 원격 HTTP 주소로 접속한 경우에도 사용할 수 있습니다.

1. **자료 검색 → 공개 대화 텍스트 직접 보관**을 펼칩니다.
2. ChatGPT·Claude·Gemini·Meta AI의 **개별 대화 주소**, 작성자와 공개 텍스트를 입력합니다. 서비스 첫 화면 주소는 사용할 수 없습니다.
3. **이 자료 보관**을 누릅니다. 최대 2만 자이며 오류가 나면 입력은 유지됩니다.
4. 위 자료 검색에서 문장을 검색하고 결과를 눌러 앞뒤 기록을 읽습니다.

이 작업은 붙여 넣은 자료만 저장합니다. 자동 웹 수집을 켜지 않으며 확장의 개별 대화 보관 선택도 바꾸지 않습니다. 같은 브라우저에서 같은 대화·작성자·본문을 다시 보내도 중복 메시지를 만들지 않습니다. 브라우저가 저장소를 차단하면 현재 탭에서는 같은 식별자를 유지하지만 새로고침 뒤의 중복 방지는 보장하지 않습니다.

`crypto.randomUUID`와 본문 해시 API를 제공하지 않는 원격 HTTP 환경도 지원합니다. 자동 감지·확장 수집이 필요한 경우에는 확장을 설치한 PC의 로컬 사무실 주소를 이용하세요.

## 상태와 데이터

**현재 확인**은 관찰 목록에 있는 Codex 대화 또는 최근 열린 것으로 확인한 웹 대화입니다. **보관 기록**은 나머지 검색 사본이며 프로세스 종료나 업무 완료를 보장하지 않습니다. Claude·Gemini CLI의 저장 기록은 실행 프로세스와 연결하지 않으므로 보관 기록으로 표시합니다.

기본 웹 감지는 계속 본문 없는 메타데이터만 사용합니다. 검색 보관은 별도 선택 기능이며 공개 메시지와 정규화한 대화 주소만 로컬로 전달합니다. 시스템 지침·추론·도구 원문·쿠키·로그인 정보는 제외하고 알려진 인증 정보·개인 경로·연락처 패턴은 마스킹합니다. 자동 마스킹이 모든 민감 문장을 판별하지는 않습니다.

검색 사본은 Docker의 `office-data` 볼륨에 있는 `session-search.sqlite`에 저장합니다. CLI 연결기 사본은 호스트의 `data/bridge/search-history`에 있습니다. 검색어·본문을 로그, 일반 상태 API, 업무 인계, Git, Docker 이미지, 공개 Wiki에 넣지 않습니다. PC 간 자동 동기화·외부 전송도 하지 않습니다.
