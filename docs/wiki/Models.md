# 직원의 모델·추론 강도와 작업 지시

감지한 **Codex 대화에 연결한 직원**은 직원 상세에서 모델·추론 강도와 작업 지시를 함께 설정할 수 있습니다. 대화 모달의 **직원 정보**, 방 안의 직원 현황 목록, 직원 관리에서 접근하세요.

## 사용 순서

1. 호스트에서 의존성을 설치합니다: 저장소 폴더에서 `npm ci` 후 `npm run bridge:codex -- --workspace .`를 실행합니다. Node.js 24.14 이상, 27 미만과 로그인된 Codex가 필요합니다.
2. 화면의 **연결 설정 → Codex 지시 전송**을 켜고 저장합니다. 적용 상태를 확인하세요.
3. 직원 상세에서 **지시할 Codex 대화 연결**을 눌러 현재 프로젝트의 대화를 선택합니다. 프로세스나 웹 탭은 저장 대화에 자동으로 연결하지 않습니다. 서버 재시작 후에는 다시 선택합니다.
4. **추론 모델**과 그 모델이 지원하는 **추론 강도**를 고릅니다. 기존 설정을 쓰려면 **현재 CLI 설정 유지**를 선택합니다.
5. **전달할 지시**에 최대 4000자로 작업을 적고 **지시 보내기**를 누릅니다. 사무실이 중지되어 있으면 같은 영역의 **사무실 업무 재개**를 먼저 누릅니다.

모델과 강도는 실제 Codex 목록에서 가져옵니다. 고정된 모델 이름이나 모든 모델에 같은 강도 목록을 제공하지 않습니다. 모델을 바꾸면 해당 모델의 기본 강도로 선택되고 다시 조정할 수 있습니다.

## 직원별 기본값 저장

직원 목록이나 상세의 **프로젝트 · 추론 설정**에서 담당 프로젝트와 기본 모델·강도를 선택한 뒤 **변경 사항 저장**을 누릅니다. 설정은 재시작 후에도 유지되며 다음 지시 화면의 기본값입니다. 저장 시 AI 지시를 전송하거나 현재 턴을 바꾸지는 않습니다. 기존 CLI 설정을 따르려면 기본값을 **현재 CLI 설정 유지**로 저장하세요. 모델 목록이 바뀌거나 연결이 끊겼다면 지원 여부를 다시 확인하며, 기존 프로젝트 배정과 설정을 임의로 지우지 않습니다.

## 적용 시점과 결과

- 선택만으로는 실행 설정이 바뀌지 않습니다. **지시 보내기**에서 다음 실행의 기본 모델·강도를 변경한 뒤 지시를 접수합니다.
- 현재 실행 중인 작업은 유지합니다. 변경한 기본값은 이미 대기 중인 지시를 포함한 이후 실행에도 사용됩니다. 원래 CLI에서 다시 설정을 바꾸면 그 선택을 따릅니다.
- 설정 변경과 지시 접수는 별도 단계입니다. 설정 적용 뒤 지시 전달이 실패할 수도 있으므로 접수 결과의 **설정 적용 확인**과 **Codex 큐에 접수됨**을 함께 확인하세요. 큐 접수는 작업 완료가 아닙니다.
- **최근 실행 모델·강도**는 관찰한 마지막 실행 기록입니다. 다음 작업에 선택한 설정과 구분합니다. 실제 승인·중단은 원래 Codex에서 처리합니다.

작성 중인 지시와 모델 선택은 같은 화면의 자동 갱신·대화창 이동 중에 유지합니다. 브라우저 새로고침에는 초안과 선택을 저장하지 않으며 접수한 지시 ID만 복원합니다. **프로젝트 · 추론 설정**에서 저장한 직원 기본값은 로컬 DB에 유지되며 직원 정의로 인계 JSON에도 포함합니다. 이 저장값과 일회성 지시 초안·최근 실행 관찰은 구분합니다.

## 문제가 있을 때

| 상태 | 다음 행동 |
| --- | --- |
| 연결할 대화 없음 | 같은 작업 폴더의 Codex에서 첫 대화를 시작하고 목록을 다시 확인합니다. 다른 직원이 사용하는 대화는 중복 연결할 수 없습니다. |
| 모델 목록 없음 | 지시 전송 적용 상태와 원래 Codex 실행을 확인합니다. 호스트가 약 30초마다 모델 목록을 다시 읽습니다. 목록 확인 전에는 현재 CLI 설정을 유지한 지시만 가능합니다. |
| 모델·강도 확인 필요 | 지원 목록이 바뀌었습니다. 현재 목록에서 다시 선택합니다. 선택을 임의의 기본값으로 바꾸지 않습니다. |
| 실행 설정 적용 실패 | 지시는 전송하지 않았습니다. Codex와 연결 프로그램을 확인하세요. 설정 변경 인터페이스를 제공하지 않는 구버전도 이 상태가 될 수 있습니다. |
| 설정 적용 확인 필요 | 지시는 보내지 않았지만 모델·강도 변경 여부는 확인하지 못했습니다. 원래 CLI에서 설정을 확인합니다. |
| 접수 여부 확인 필요 | 원래 CLI에서 접수 여부를 먼저 확인합니다. 자동 재전송하지 않습니다. |

웹 탭·Claude·Gemini 등 다른 공급자의 감지는 관찰 용도입니다. 해당 연결의 모델·강도와 지시는 원래 서비스에서 조작합니다. 새 AI 실행이나 웹 메시지 전송 기능으로 표시하지 않습니다.

모델 조회와 설정·큐 인터페이스는 Codex CLI/App Server 0.163.0 기준으로 확인했습니다. 자동 검증에는 격리된 모의 서버를 사용하며 현재 사용 중인 실계정 세션에 시험 지시를 보내지 않습니다. [공식 App Server 문서](https://learn.chatgpt.com/docs/app-server), [CLI 연결 안내](CLI.md).
