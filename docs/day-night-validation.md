# 사무실 낮·밤 환경 검증 — 2026-10-22

화면에 적용된 테마를 기준으로 라이트는 낮, 다크는 밤 환경을 표시한다. 실제 시각이나 직원의 업무 상태로 낮·밤을 결정하지 않는다.

- 낮: 밝은 하늘과 주간 도시, 자연광과 바닥의 햇빛. 실내등의 발광을 낮춘다.
- 밤: 밤하늘과 도시 불빛, 따뜻한 실내등과 푸른 주변광. 낮의 햇빛을 숨긴다.
- 창밖·등의 변경 가능한 재질은 가구·캐릭터의 공용 재질과 분리한다. 테마 전환은 기존 장면과 재질을 갱신하며 방·층·카메라·캐릭터를 다시 생성하지 않는다.

## 자동 검증

`npm test`에서 **203개 통과**. 장면 관련 검사는 `node --test tests/ui/office-scene.test.mjs tests/ui/theme.test.mjs`로 실행한다.

세 층의 낮·밤 전환, 반복 전환 후 복원, 다른 장면의 재질 보존, 선택하지 않은 층의 숨김 유지, 카메라·확대·캐릭터·이동 유지와 WebGL 실패 시 탐색을 확인했다.

## 브라우저 검증

실제 WebGL 장면을 별도 검증용 서버와 가상 직원·대화로 확인했다. 실제 사용자 DB·연결기·AI 지시를 사용하지 않았다.

- 1·2·3층 및 전체 건물의 두 테마 **8개 보기**를 확인하고 화면을 직접 비교했다.
- 320·390·768·1366·1920px에서 양 테마 **10개 배치**의 가로 넘침과 글자 최소 크기를 확인했다.
- Chrome 실제 탭 확대율 200%에서 두 테마를 확인했다. 1366px 창에서 CSS 너비 683px, devicePixelRatio 2이며 장면 조작 글씨는 16px 이상이고 문서의 가로 넘침은 없었다.
- 층·확대·장면과 캐릭터 객체 유지, 네이티브 전체화면에서 테마 전환, 기기 설정 변경, 명시한 테마 우선, 새로고침 복원과 다른 탭의 테마 변경 중 양식 초안 보존을 확인했다.
- 브라우저 자바스크립트 오류는 없었다. 테마별 장식은 움직이지 않으며 동작 줄이기 설정을 유지한다.

Git 통합과 실행 서버·Wiki 반영은 검증 후 별도 배포 단계에서 확인한다.
