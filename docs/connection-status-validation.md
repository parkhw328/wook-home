FR-54에 따라 감지 목록, 감지기별 연결 상태, 연결 점검, 설정 적용과 직원 연결의 색상·아이콘·문구를 통일했다. 정상 관찰은 초록색, 활동·점검 정보는 파란색, 확인 필요는 황토색, 끊김·오류는 빨간색, 종료·미사용은 중립색이다. 감지 정상과 실제 실행·로그인·업무 완료를 구분한다.

## 자동 검증

`946cb9b`를 기준으로 상태 표시 변경만 적용한 별도 사본에서 다음 명령으로 **178개 테스트가 모두 통과**했다. 동시 진행하던 대화상자·브라우저 ID 변경은 이 사본에서 제외했다.

```sh
npm ci --ignore-scripts
node --test tests/server/*.test.js tests/ui/*.test.mjs tests/extension/*.test.mjs
```

`tests/ui/connection-status.test.mjs`, `tests/ui/discovery.test.mjs`, `tests/ui/bridge-settings.test.mjs`는 정상·오류·미설정·종료·오래된 결과·일부 감지의 구분, 알려지지 않은 상태의 확인 필요 처리, HTML 문자 이스케이프, 서버 수신 실패 후 정상 표시 해제, 실제 적용 상태와 켜짐/꺼짐·적용 대기를 확인한다. 기존 직원 연결·서버·브라우저 확장 테스트도 함께 통과했다.

- 라이트·다크 각각 320·390·768·1366·1920px에서 감지·연결 점검·설정 탭을 확인했다. 최종 계산 글꼴은 보조·상태 14px 이상, 버튼·입력 16px 이상이며 글자 대비를 검사했다.
- 200% 글꼴 확대와 683px 재배치에서 같은 세 탭의 읽기·조작·가로 넘침을 확인했다. 강제 색상 모드에서도 상태 문구와 아이콘을 유지했다.
- 실행 프로세스·열린 탭·활동 기록·턴 종료 기록·최근 프로세스 종료를 구분했다. 감지기가 정상인 빈 목록과 일부 감지·감지 불가도 확인했다.
