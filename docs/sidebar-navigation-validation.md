# 0.2.3 상단 계정 메뉴·도움말 링크 검증

2026-10-28에 FR-78을 기준으로 확인했다. 합성 계정과 기록으로 브라우저 동작을 점검했으며 실제 AI 호출·지시 전송은 수행하지 않았다.

## 변경 범위

- 상단 admin 버튼을 누르면 비밀번호 변경·로그아웃이 나타난다. 기본 화면에서는 접고, 메뉴 바깥 선택·Escape·화면 이동으로 닫는다. 비밀번호 모달을 닫으면 상단 계정 버튼으로 초점이 돌아간다.
- StackQueue Blog 이름은 기존 18px 크기를 유지하며 한 줄로 표시한다.
- 하단 도움말은 Wiki 사용설명서로, 버전 번호는 현재 태그의 CHANGELOG로 연결한다. 두 링크는 새 탭으로 열리고 별도의 화면 사용법·중복 도움말 항목은 제거했다.

## 검증 결과

- `npm test`: 240개 통과. 새 계정 메뉴와 비밀번호 모듈의 구문 검사도 기존 진입점 검사에 포함했다.
- `node tests/browser/density-preview.mjs`와 `python3 tests/browser/density.py`: 290개 화면·상호작용 점검 통과. Chromium의 라이트·다크 각각 320/390/768/1366/1920px 및 1366px 창에서 실제 탭 확대 200%를 사용했다.
- 계정 메뉴의 Enter·Space 열기, Tab 이동, Escape·바깥 선택·화면 이동 닫기, 갱신 중 열린 메뉴·초점 보존과 터치로 비밀번호 모달 열기를 확인했다. 기존 8자 비밀번호 경계·변경·세션 폐기·로그아웃·재로그인과 늦은 저장 응답 회귀도 통과했다.
- 메뉴가 화면 밖으로 넘치지 않고 버튼은 44px/16px 이상이며 비밀번호 창을 닫으면 메뉴가 접힌 채 상단 버튼에 초점이 돌아온다. 블로그 이름은 18px 이상·한 줄·잘림 없음, 도움말·버전 링크는 44px 이상으로 확인했다. 링크 클릭은 외부 요청을 가로채 새 탭의 목적지 URL과 `noopener noreferrer`를 검증했다. 외부 사이트 본문 검증은 포함하지 않는다.
- 로그인·사무실·전체화면·업무 보드·자료 검색·인계·연결 설정과 상세창의 페이지 가로 넘침·최소 글자·평면 UI·모달 닫기·초안 유지·브라우저 오류를 함께 확인했다.

합성 캡처는 Git에서 제외된 `artifacts/density/`와 `artifacts/sidebar/`에 저장했다. 두 테마의 320/1366px 계정 메뉴 화면을 직접 확인했다. 재현 절차는 [개발 안내](development.md#화면-밀도계정-변경-검증)를 따른다. 다른 브라우저 전체 적합성이나 모든 공급자의 실계정 연동을 의미하지 않는다.

## 배포·기록

- 구현 커밋 `f458bfb`와 같은 위치의 `v0.2.3` 태그를 게시했다. 태그의 변경 이력 링크가 배포 전에 준비되도록 순서를 맞췄다. GitHub Release 페이지·다운로드 배포물은 별도로 게시하지 않았다.
- `wook-home-office:f458bfb` 이미지에서 Node 24.14 인증·모듈 구문 검증 2개를 통과했다. 기존 Compose 서비스는 healthy이며 `/api/health`가 0.2.3을 반환한다. 배포한 계정 메뉴·비밀번호 모듈·HTML·CSS·JS·package.json은 검증한 소스와 일치한다.
- 교체 전후 계정 파일 다이제스트, 직원 설정·대기실 메모, 프로젝트·업무·세션 등록 기록, 환경 변수·마운트·포트를 비교해 보존을 확인했다. 기존 데이터 볼륨·읽기 전용 루트·8080 바인딩과 호스트 연결기를 유지했다. 교체 전과 중지 후에 업무가 없는 것을 확인하고 사무실의 업무 접수 상태도 원래 값으로 복원했다. 실제 업무 재실행·지시 재전송은 없었다.
- 운영 8080 주소의 320/1366px 로그인 화면·0.2.3 표시·8자 입력 기준·미로그인 업무 API 401·브라우저 오류 없음을 확인했다. 운영 비밀번호 입력·변경은 하지 않았다. 서버 재시작 후 기존 비밀번호로 다시 로그인한다.
- GitHub Wiki의 Home·Login·UI 원본을 동기화한 `0d269a1`을 게시했다.
