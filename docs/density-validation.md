# 0.2.1 화면 밀도·탐색·관리자 비밀번호 검증

2026-10-28에 FR-74~76을 기준으로 확인했다. 운영 데이터와 계정을 변경하지 않는 합성 기록 검증이며 실제 AI 호출·지시 전송은 수행하지 않았다.

## 변경 범위

- 하단 방 이동은 층 번호·아이콘으로 축약하고 프로젝트·방 전체 이름은 툴팁으로 제공한다. 마우스 올림·키보드 초점·터치를 지원하며 전체 건물·층 이동을 유지한다.
- 움직임 조작을 맵 상단으로 옮겼다. 장식 움직임과 CLI 감지는 구분한다.
- 로그인·사무실·업무 보드·검색·인계·직원/연결 관리·대화창에서 간격·고정 높이·반복 소개를 정리했다. 연결 설정 바로가기는 본문 전체 폭을 사용한다.
- admin 비밀번호는 기존과 다른 8~256자로 변경한다. 사무실 내부 모달과 최초 변경 화면·서버의 길이 기준을 일치시켰다. 기존 계정 해시·세션 정책은 유지한다.

## 자동 검증

- `npm test`: 240개 통과. 인증 API의 7자 거부·정확히 8자 허용·257자 거부·동일 비밀번호 거부·현재 비밀번호 오류·다른 로그인 폐기·재시작·만료·재시도 제한을 포함한다.
- `node tests/browser/density-preview.mjs`와 `python3 tests/browser/density.py`: Chromium의 278개 화면·상호작용 점검 통과. 라이트·다크 각각 320/390/768/1366/1920px 및 1366px 창의 실제 탭 확대 200%를 사용했다. 최종 계산 글자 14px 이상, 일반 입력·버튼 16px/44px 이상, 모달 제목 22px 이상, 페이지 가로 넘침·그림자·JS 오류 없음, 모달 닫기 노출을 확인했다.
- 로그인, 사무실, 전체화면, 비밀번호 모달, 채용, 현황 상세, CLI 대화·검색 조건 복원, 직원 상세·지시·설정·연결, 대기실 수정, 히스토리, 업무 목록·지시 양식·보고 답변, 자료 검색·보관 대화·직접 보관 양식, 인계, 연결 설정·실행 안내·감지·점검 탭을 확인했다.
- 마우스 툴팁의 전체 프로젝트명, Escape 닫기, 방향키 이동과 좁은 화면의 스크롤, 터치 한 번으로 이동하면서 이름 표시, 전체화면 툴팁을 확인했다. 키보드 스크롤로 정지한 마우스 아래 버튼이 바뀌더라도 초점 항목의 이름을 유지하도록 보정했다.
- 비밀번호 모달의 7/8자 경계·불일치·현재 비밀번호 오류·저장 성공·다른 로그인 해제·새 비밀번호 재로그인, 닫을 때 입력 삭제·초점 복원·창 바깥 닫기, 저장 응답이 늦게 와도 닫은 모달을 다시 열지 않는 동작을 확인했다.
- `node tests/browser/office-update-preview.mjs`와 `python3 tests/browser/office-update.py`: 두 테마·5개 너비·실제 200% 확대의 12개 시나리오 통과. 프로젝트 층·대기실 메모 저장·오프라인 기록·페이지 이동·대화의 HTML 비실행·전체화면·로그아웃 회귀를 확인했다.
- 동작 줄이기를 끈 별도 합성 브라우저에서 상단 움직임 버튼의 켜짐→꺼짐 전환도 확인했다.

## 화면 증빙과 재현

합성 화면은 `artifacts/density/`, 기존 기능 회귀 화면은 `artifacts/office-update/`에 저장한다. 로그인·사무실·검색·인계·설정·비밀번호·CLI 창의 라이트/다크와 320/1366px 캡처를 직접 확인했다. 화면 전환 뒤 두 렌더링 프레임을 기다려 이전 화면의 높이가 캡처에 남지 않게 했다. 실제 계정·대화·로컬 참고 자료는 증빙·Git·이미지·Wiki에 넣지 않았다. 실행 절차는 [개발 안내](development.md#화면-밀도계정-변경-검증)에 있다.

모바일의 입체 장면과 방 탐색은 내부 가로 스크롤을 유지한다. 브라우저 검증은 Chromium이며 다른 브라우저 전체 적합성이나 모든 공급자의 실계정 연동을 의미하지 않는다. 화면 여백 조정은 기존 14/15/16/17/22px 글자 기준과 44px 조작 기준을 낮추지 않는다.
