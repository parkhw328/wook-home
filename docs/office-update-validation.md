# 0.2.0 로그인·프로젝트 층·대기실·작업 히스토리 검증

2026-10-28 변경. 합성 계정과 격리 DB에서 검증했으며 실제 AI 지시를 전송하지 않았다.

## 자동 검증

- `npm test`: 240개 통과. Node 기본 러너의 server/ui/extension 검증. 로그인·초기 비밀번호 변경·세션 만료/폐기·반복 실패 제한, 미인증 API 차단과 기존 Host/Origin 검사를 포함한다.
- `tests/server/projects-history.test.js`: 같은 이름의 서로 다른 작업 폴더 격리, 재시작 후 층 번호·배정·메모 보존, 메모와 배정의 충돌 검사, 이전 프로젝트의 오프라인 사본 열람, 페이지 이동, 취소 업무와 완료 구분·인계 제외.
- `tests/ui/project-floors.test.mjs`: 프로젝트별 방·직원·업무 필터, 공용 공간과 다른 층의 엘리베이터 동선.
- 패키지·API·화면은 package.json의 0.2.0을 사용한다.

## 실제 브라우저

```bash
node tests/browser/office-update-preview.mjs
python tests/browser/office-update.py
```

격리 서버의 합성 계정·직원·업무·보관 메시지만 사용한다. Chromium에서 라이트·다크 × 320/390/768/1366/1920px 및 두 테마의 실제 200% 브라우저 확대, 총 12개 배치를 검증했다.

- 로그인 실패·성공·로그아웃 후 API 접근 차단.
- 프로젝트별 사무실 이동·전체 4층 보기·대기실 메모 저장.
- 종료 상태의 CLI 보관 대화 열람·HTML 비실행·종류 필터·페이지 이동.
- 읽기 글꼴 최소 14px, 버튼/입력 16px·높이 44px 이상, 가로 넘침 없음·평면 버튼.
- 전체화면 진입/종료, 대화 모달 닫기, JavaScript 오류 없음.

화면과 결과 JSON은 Git 제외 `artifacts/office-update/`에 보관한다. 역사 자료는 수집한 사본만 제공하며 수집하지 않은 대화의 복원이나 실제 공급자 실행 종료를 검증한 것은 아니다. 여러 프로젝트의 동시 호스트 수집은 후속 범위이며 현재 연결기 하나는 한 작업 폴더를 관찰한다.

Docker 이미지 빌드·Compose 설정 검사를 통과했다. 인증 자료는 영속 데이터 디렉터리에만 만들고 이미지에는 포함하지 않는다. 실제 실행 반영 결과는 아래에 별도로 기록한다.
