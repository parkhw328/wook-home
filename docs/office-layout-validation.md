# 실내 사무실 재작성 검증 — 2026-10-22

## 구현 범위

기본 시점을 2층 내부로 바꾸고 1층 라운지·다과실, 2층 업무 사무실·유리 회의실, 3층 대표이사실·발표 공간을 구성했다. 목재 바닥·야간 창문·유리벽·출입문·가구와 인물은 자체 제작 지오메트리다. 오른쪽 층 안내는 실제 배치 인원을 표시하고 전체 건물 보기에서는 방 중심으로 탐색한다. 작은 화면에서는 층 안내를 장면 위에 배치한다.

## 자동 검증

- 확정 기반 코드에 이번 변경을 복사한 별도 트리의 `npm test`: **138개 통과**.
- 모든 방 사이 문·복도·엘리베이터 경로, 아홉 책상 및 추가 인원 위치에서 가구를 통과하지 않는 동선, 회의·발표 좌석과 문 사이 경로를 확인했다.
- 겹친 이름표 16개를 글자·버튼 축소 없이 화면 안에서 분리하는 배치와 원래 위치 데이터 보존을 검증했다. 브라우저에서도 이동 중 일곱 이름표의 겹침이 없고 조정된 이름표에 직원 연결선이 표시됨을 확인했다.
- 층별·전체 건물 카메라의 세로·가로·초광폭 비율과 실제 모델의 건물 경계를 검증했다. 창문이 외벽 밖으로 돌출하던 부분도 보정했다.
- WebGL 미지원 시 탐색 유지, 렌더 루프 정지 시 이동 완료, 활동 중 목적지 변경·연결 끊김, 늦은 대화 응답 차단 등 기존 회귀 검증을 포함한다.

## 브라우저 검증

- Chrome에서 1·2·3층과 전체 건물, 목재·창문·회의실·라운지·발표 공간을 시각 확인했다. 격리된 합성 세션으로 책상·복도 보행과 협업·질문 공간 배치를 검증했다.
- 전체화면 대체 보기에서 왼쪽 여백을 제거하고 장면·층 안내를 화면 폭에 맞췄다. 방 입장과 대화 모달, 닫기·재열기 시 검색어·역할 필터 보존을 확인했다.
- 320·390·768·1366·1920·2560px에서 페이지 가로 넘침이 없었고 장면은 필요할 때 자체 영역 안에서 좌우로 이동했다. 읽는 글자는 최소 14px, 일반 버튼은 최소 16px·44px를 확인했다.
- 모바일 대화 모달의 본문 17px·검색 입력 16px·시각 14px, 닫기·검색·작성자 필터와 채용 양식의 다크 테마 대비를 확인했다. 실제 업무 데이터에는 검증용 직원을 추가하지 않았다.
- 검증 브라우저가 네이티브 전체화면을 허용하지 않아 브라우저 안의 대체 보기만 검증했다. 200% 브라우저 확대와 실제 WebGL 미지원 장치 검증은 포함하지 않았다.
