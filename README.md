# wook-home

**AI 직원들이 모이는 나만의 가상 회사.**

여러 AI 에이전트에 업무를 맡기고, 질문에 답하며, 결과를 한곳에서 판단하는 Commander의 작업 공간을 준비하고 있습니다.

현재는 **설계·요구사항 정리 단계**입니다. 실행 가능한 앱과 Docker 배포물은 아직 제공하지 않습니다.
